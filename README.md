# Understanding Algorithms and Graphs

Repositório dedicado ao estudo e à implementação de **algoritmos, estruturas de dados e teoria dos grafos**, com foco em compreender os conceitos por trás de cada implementação.

## 🎯 Objetivo

Este projeto tem como objetivo transformar o estudo teórico de algoritmos em implementações práticas, buscando compreender não apenas **como** um algoritmo funciona, mas também **por que** ele funciona e quais são seus custos computacionais.

## 📚 Conteúdos

- Algoritmos de ordenação
- Estruturas de dados
- Análise de complexidade
- Recursão
- Busca em grafos
- Algoritmos em grafos
- Representação de grafos
- Problemas clássicos de Computação

## 🛠️ Tecnologias

- **Python**
- **Git**
- **GitHub**

## 📌 Organização

As implementações são desenvolvidas de forma incremental, acompanhando o estudo teórico de cada algoritmo ou estrutura de dados.
